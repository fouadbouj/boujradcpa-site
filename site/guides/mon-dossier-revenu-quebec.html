Accéder à Mon dossier de Revenu Québec

Mon dossier pour les citoyens vous permet de consulter vos avis de cotisation, vos relevés (relevé 1, relevé 31…), vos remboursements et vos crédits, et de faire plusieurs démarches en ligne.

Option 1 : avec votre institution financière (la plus rapide)

Pas besoin d’avoir un avis de cotisation récent : vous utilisez les accès de votre banque en ligne.

  1. Allez sur le site de Revenu Québec

    Cliquez sur Mon dossier, section Citoyens, puis sur Accéder à Mon dossier.

  2. Choisissez votre institution financière

    Cliquez sur son logo, puis connectez-vous avec le même code et le même mot de passe que sur le site de votre banque.

  3. Acceptez les conditions et confirmez votre identité

    Répondez aux questions demandées.

  4. Inscrivez-vous à Mon dossier

    Suivez les instructions à l’écran. La prochaine fois, vous passerez directement par votre banque.

Option 2 : avec un compte du service d’authentification du gouvernement

Cette option demande un avis de cotisation récent de Revenu Québec, car des renseignements qui y figurent vous seront demandés.

  1. Accédez à Mon dossier, puis choisissez le service d’authentification gouvernemental

    Le gouvernement remplace graduellement clicSÉQUR par ce nouveau service; si vous avez déjà un compte clicSÉQUR, il fonctionne encore : connectez-vous simplement.

  2. Créez votre compte

    Choisissez un code d’utilisateur, vos options de sécurité et vos questions de sécurité, puis acceptez les conditions d’utilisation.

  3. Confirmez votre identité

    Entrez les renseignements demandés, tirés de votre avis de cotisation.

  4. Inscrivez-vous à Mon dossier

    Suivez les instructions à l’écran.

Code ou mot de passe oublié? Revenu Québec devra vérifier votre identité de nouveau. Le plus simple est alors de passer par votre institution financière (option 1).
